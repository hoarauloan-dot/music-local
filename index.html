Stockage, installation et limites

1. Ouvre cette page dans Safari, puis Partager → Sur l’écran d’accueil. Lance ensuite le lecteur depuis cette nouvelle icône.

2. Importe deux petits MP3 depuis Fichiers. Attends « Prêt hors ligne », puis lis le premier et verrouille l’écran jusqu’au suivant.

3. Ferme le lecteur, active le mode avion et rouvre-le depuis son icône. Vérifie que tes titres sont encore là et lisibles.

Garde tes originaux : effacer les données du site ou certaines contraintes de stockage peuvent supprimer cette copie locale. Safari et l’icône installée peuvent utiliser des espaces de stockage distincts : importe depuis l’icône.

Version 0.2 : playlists, artistes, albums, favoris, pochettes, file modifiable et informations éditables. Lecture des tags MP3 ID3 courants et des tags M4A/MP4 de type iTunes ; certains tags ne sont pas reconnus. Une pochette peut être ajoutée manuellement.

MP4 : le fichier vidéo entier est conservé. Pas encore d’extraction audio ni de réception via Partager iOS. La continuité de lecture écran verrouillé dépend d’iOS : teste-la avec deux morceaux avant de remplir ta bibliothèque.

Le bouton ci-dessous exporte les playlists et informations seulement, sans les fichiers audio ni les pochettes. Garde tes originaux séparément.
